SNOW RUSH - UNITY 6 UI REFRESH

This project refreshes the in-game interface using the uploaded Woodland Dash reference as visual guidance. It is a native Unity game: no WebView and no embedded website.

DESIGN CHANGES
- Full-screen title screen with large SNOW RUSH branding
- Dark navy translucent panels, icy cyan accents, gold stats and red primary action buttons
- Start Climb and Basecamp Gear menu
- Coin and best-distance displays
- In-game altitude/coin HUD and pause button
- Pause overlay, restart and return-to-basecamp actions
- Game-over summary and replay controls
- Camera cycling and sound toggle
- Desktop keyboard controls plus on-screen movement/jump/slide buttons

OPEN IN UNITY 6
1. Extract this ZIP.
2. Open Unity Hub -> Add -> Add project from disk.
3. Select the extracted SnowRunner_UI_Refresh folder.
4. Wait for Unity to import the project and install Unity UI (UGUI) if prompted.
5. In Unity, use menu Snow Runner -> Create Snow Rush Scene.
6. Open Assets/Scenes/SnowRunner.unity and press Play.

CONTROLS
A / Left Arrow: move left
D / Right Arrow: move right
Space: jump
S / Down Arrow: slide
Esc: pause

NOTES
- This is a refreshed native Unity scene and UI layer. The Basecamp Gear screen is currently a styled placeholder for future upgrade functionality.
- The project uses Unity's built-in Arial legacy UI Text component to avoid requiring TextMeshPro font setup.
